# React Component Output Directory

This directory contains compiled React components and their TypeScript declarations.

## Structure

Each subdirectory contains:
- `index.js` - Compiled JavaScript bundle (generated by `tsup` from `src2/`)
- `index.d.ts` - TypeScript declaration file (manually maintained)

## TypeScript Declarations

The `.d.ts` files are **manually maintained** because auto-generating them with `tsup` causes out-of-memory errors due to the large VS Code type definitions.

These declaration files provide type safety for imports without the memory overhead of full type generation.

### Updating Declarations

If you add/modify exported functions in the React components, update the corresponding `.d.ts` file:

1. Locate the component source in `src2/`
2. Find the mount function signature
3. Update the corresponding `out/*/index.d.ts` file

## Building

To rebuild the JavaScript bundles:

```bash
cd src/vs/workbench/contrib/ainative/browser/react
node build.js          # One-time build
node build.js --watch  # Watch mode
```

Or from the root:

```bash
cd ainative-studio
npm run buildreact     # One-time build
npm run watchreact     # Watch mode
```

## Git Tracking

Both `.js` and `.d.ts` files in this directory are tracked in git to ensure:
- Type safety in development
- Consistency across environments
- No build requirement for type checking
